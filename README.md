# Tildeck

A free, open source SSH client for Windows and Android with end-to-end encrypted sync through a self-hosted server.

**Status: early foundation work.** The sync server, admin panel, and client app exist as foundation shells. Nothing in this repository can be installed or used yet.

The plan, its decisions, and its open blockers are in [docs/project-foundation.md](docs/project-foundation.md).
